# השוואת פלטפורמות מסחר עצמאי בישראל

עמוד סטטי אחד (`index.html`) שמשווה בין מיטב טרייד, אקסלנס טרייד, אינטראקטיב ישראל ובלינק:
מינימום הפקדה, עמלות בארץ ובחו"ל, דמי טיפול, המרת מט"ח, יתרונות וחסרונות, וקישורי שותפים לפתיחת חשבון.

## מבנה

- אין תלויות ואין שלב בנייה. פותחים את `index.html` בדפדפן.
- הצבעים מוגדרים כמשתנים ב־`:root`, עם ערכה כהה (`prefers-color-scheme` וכפתור החלפה ששומר את הבחירה ב־`localStorage`).
- לכל כפתור הצטרפות יש `data-platform`, שאפשר לחבר לכלי אנליטיקס כדי למדוד קליקים.

## עדכון הנתונים

1. לעדכן את תאריך העדכון בשורת ה־`eyebrow` שבראש העמוד. זה המקום היחיד שבו הוא מופיע, ושאר העמוד מפנה אליו.
2. לעדכן את הטבלה ואת כרטיס הפלטפורמה המתאים, ולוודא שהמספרים זהים בשניהם.
3. לבדוק שהטבות ההצטרפות עדיין בתוקף.

## קישורי שותפים

כל הקישורים לפתיחת חשבון מסומנים `rel="sponsored noopener"`, כפי שגוגל מבקשת לסמן קישורים ממומנים.
ליד כל כפתור מופיעה הערת "קישור שותפים", ובתחתית העמוד יש גילוי נאות מלא.
